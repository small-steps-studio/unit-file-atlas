# Getting started

1. Install **Unit File Atlas** (publisher SmallStepsStudio) from the Extensions view.
2. Open a systemd unit file (.service, .timer, .socket and so on), or run **Unit File Atlas: Open Sample File** to open the invented sample.
3. Open the Command Palette (`Ctrl+Shift+P`, on macOS `Cmd+Shift+P`), type `Unit File Atlas` and pick a report. The button in the editor title bar of .service, .timer, .socket, .path, .mount, .automount, .swap, .slice, .scope, .target files runs **Show Unit Overview**.
4. The report opens as a new Markdown document (and its preview). Save it, copy it into a ticket, or close it.
5. **Unit File Atlas: Open Walkthrough** shows the same steps inside the editor.

Every report is described in [reports.md](reports.md). Licence and trial: [licence.md](licence.md). Problems: [troubleshooting.md](troubleshooting.md).
